# Agent instructions

This repo is a fork of `JosiahHands/numberGame`. Cloudflare deploys the live site from `main` in `JosiahHands/numberGame`, not from this fork.

## Pull requests

When you edit this repo and are asked to "make a pull request", open it from this fork into `JosiahHands/numberGame`, with base `main`:

```sh
gh pr create -R JosiahHands/numberGame --base main --head Wardcode-frame:<branch>
```

Do not merge it. The owner reviews and merges every pull request.
